# project-DLP
Web based Digital Learning Platform

A comprehensive, secure, and multi-language school digital learning platform build to streamline administrative tasks, teacher-student management, and daily school operations.

## 🌐 Live Webpage
You can access the live application here: **[gnssdlp.rf.gd](https://gnssdlp.rf.gd/)**

---

## ✨ Key Features

* **Multi-Role Authentication**: Secure portals tailored specifically for **Admins**, **Teachers**, and **Students**.
* **Enhanced Security**: Features a secure login gateway equipped with bot-protection checks and session timing.
* **Bilingual Language Engine**: Fully integrated support for switching seamlessly between **English** and **Hindi (हिंदी)**.
* **Admin Overview Dashboard**: Interactive data visualization charts (powered by Chart.js) and quick-action tools for managing records.
* **Responsive Design**: Modern user interface featuring responsive grids and glassmorphism design styles.

---

## 🛠️ Tech Stack

* **Backend:** PHP, MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Libraries & Assets:** FontAwesome Icons, Chart.js

---

## 🚀 Getting Started (Local Setup)

1. Clone or download the repository to your local server (e.g., XAMPP/WAMP).
2. Import the project database into your MySQL server.
3. Update your database connection details inside `backend/db_connect.php`.
4. Run the project locally or visit the live deployment at **[www.gnssdlp.rf.gd](http://www.gnssdlp.rf.gd)**.
